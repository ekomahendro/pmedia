3. Silabus Informatika — Software Development & Database (6 JP/minggu)

Tujuan umum: siswa mampu mengembangkan aplikasi web sederhana, memahami logika pemrograman, dan mengelola database (MySQL/SQLite).

Kelas 7 — Dasar Komputasi & Web Programming

  • Pengantar informatika: hardware, software, etika digital
  • Logika & algoritma dasar (flowchart, pseudocode)
  • HTML dasar & struktur dokumen
  • CSS dasar — styling sederhana
  • Mini Project 1: Personal Website Portfolio

Kelas 8 — Programming & Dynamic Web

  • JavaScript dasar (variabel, kondisi, loop, fungsi)
  • DOM manipulation & event handling
  • Pengantar database: konsep tabel, relational DB
  • CRUD dasar dengan server sederhana (mis. PHP + MySQL atau Node.js + SQLite)
  • Mini Project 2: Aplikasi To-do List + Database

Kelas 9 — Full Stack Basic & Final Project

  • Backend dasar (pilih PHP atau Node.js) — routing & form handling
  • Database: CREATE, INSERT, UPDATE, DELETE, JOIN sederhana
  • Session & pengamanan dasar (validation, hashing sederhana)
  • Deployment dasar (hosting lokal / shared hosting)
  • Project Akhir: Aplikasi Web Sekolah (Login, CRUD, Role sederhana)

Metode pembelajaran: project-based learning, pair programming, code review, dan presentasi proyek.

4. Silabus English Intensive (4 JP/minggu)

Tujuan: keterampilan komunikasi aktif, persiapan TOEFL Junior, dan kemampuan presentasi.

Kelas 7

  • Grammar dasar & tenses simple
  • Conversational English (daily expressions)
  • Pronunciation fundamentals
  • Vocabulary building
  • Mini Project: Short Speech Recording

Kelas 8

  • Intermediate grammar (passive voice, gerund)
  • Applied English (shopping, travel, school)
  • Writing short essays
  • Listening comprehension
  • Mini Project: English Vlog

Kelas 9

  • Academic English & public speaking
  • Formal writing (emails, reports)
  • Debate & presentation skills
  • TOEFL Junior preparation
  • Mini Project: 5–7 minute English Presentation

Penilaian: rubric speaking, portfolio, tes listening, dan praktek tertulis.

5. Silabus Mathematics Olympiad (2 JP/minggu)

Tujuan: menyiapkan peserta KSN-K (Kompetisi Sains Nasional tingkat Kabupaten/Kota) dan kompetisi matematika lainnya.

Kelas 7 — Dasar Olimpiade

  • Bilangan bulat, FPB & KPK
  • Pola & barisan
  • Logika & problem solving
  • Geometri dasar non-rumus
  • Challenge set mingguan

Kelas 8 — Intermediate

  • Aljabar olimpiade
  • Persamaan fungsional dasar
  • Kombinatorika & teknik counting
  • Geometri koordinat
  • Soal-soal KSN sebelumnya

Kelas 9 — Advanced

  • Geometri olimpiade (lingkaran, sudut, segitiga)
  • Kombinatorika menengah

RPP — Format Kemendikbud (CP • ATP • Tujuan • Langkah • Penilaian)

Di bawah ini contoh RPP lengkap untuk tiga mata pelajaran (format disederhanakan sesuai CP-ATP-Tujuan-Langkah-Penilaian).

RPP Informatika — Modul: HTML & CSS (4 Pertemuan)

CP (Capaian Pembelajaran): Siswa mampu membuat halaman web statis sederhana menggunakan HTML dan CSS serta memahami struktur dokumen web.

ATP (Alokasi Waktu Pembelajaran): 4 x 40 menit (4 pertemuan)

Tujuan Pembelajaran:

  • Siswa dapat menuliskan struktur dasar HTML (html, head, body).
  • Siswa mampu menggunakan tag dasar (h1-h6, p, a, img, ul/ol, li).
  • Siswa dapat menerapkan CSS sederhana untuk styling teks dan layout.

Langkah Kegiatan (per pertemuan):

  1. Pertemuan 1: Apersepsi -> Demonstrasi struktur HTML -> Latihan membuat file index.html -> Tugas rumah: buat halaman biodata sederhana.
  2. Pertemuan 2: Review tugas -> Penjelasan tag multimedia & link -> Latihan menambah gambar & link -> Quiz singkat.
  3. Pertemuan 3: Pengenalan CSS internal -> Properti warna, font, margin -> Latihan styling biodata.
  4. Pertemuan 4: Layout dasar (flexbox intro) -> Finalisasi mini-project -> Presentasi & peer review.

Penilaian: Observasi praktik (40%), Tugas proyek (40%), Quiz & presentasi (20%).

RPP Informatika — Modul: CRUD & Database (6 Pertemuan)

CP: Siswa mampu membuat aplikasi web sederhana dengan fitur CRUD terhubung ke database (MySQL/SQLite).

ATP: 6 x 40 menit

Tujuan Pembelajaran:

  • Siswa memahami konsep relasional database dan tabel.
  • Siswa dapat membuat formulir input dan menyimpan data ke DB.
  • Siswa mampu menampilkan, mengubah, dan menghapus data melalui antarmuka web.

Langkah Kegiatan (ringkas): Setup DB & koneksi -> Form input & insert -> Menampilkan data -> Update & delete -> Validasi & sanitasi -> Deployment sederhana.

Penilaian: Fungsionalitas aplikasi (50%), Kualitas kode & dokumentasi (30%), Presentasi proyek (20%).

RPP English Intensive — Modul: Speaking & Listening (8 Pertemuan)

CP: Siswa mampu berkomunikasi sederhana menggunakan kalimat tanya & jawab, memahami percakapan singkat, dan menyampaikan presentasi 2–3 menit.

ATP: 8 x 40 menit

Tujuan Pembelajaran:

  • Menguasai frasa dan kalimat tanya dasar.
  • Meningkatkan kelancaran berbicara melalui roleplay.
  • Mampu melakukan presentasi singkat secara berbahasa Inggris.

Langkah Kegiatan: Warm-up -> Model conversation -> Pair practice -> Listening exercise -> Mini-presentation -> Feedback.

Penilaian: Speaking fluency (40%), Listening test (30%), Presentation & peer feedback (30%).

RPP English Intensive — Modul: Academic Writing (6 Pertemuan)

CP: Siswa mampu menulis teks deskriptif dan short report dalam bahasa Inggris.

ATP: 6 x 40 menit

Tujuan: Menyusun paragraf, struktur teks, dan menggunakan linking words.

Langkah: Brainstorm -> Model text -> Guided writing -> Independent writing -> Peer editing -> Final submission.

Penilaian: Struktur & kohesi (40%), Grammar & vocabulary (30%), Kebersihan & format (30%).

RPP Math Olympiad — Modul: Kombinatorika & Counting (6 Pertemuan)

CP: Siswa dapat menyelesaikan soal kombinatorika dasar serta menerapkan prinsip counting dalam problem solving.

ATP: 6 x 40 menit

Tujuan: Menguasai permutasi, kombinasi, dan teknik counting sederhana.

Langkah: Konsep dasar -> Latihan bertahap -> Problem solving kelompok -> Try out mini -> Review & strategi.

Penilaian: Latihan harian (30%), Ujian mini (40%), Try out (30%).

LKPD (Lembar Kerja Peserta Didik) — Contoh Untuk Cetak/Bagikan

LKPD Informatika: Mini Project "Personal Portfolio" (Kelas 7)

  1. Tujuan: Membuat halaman web sederhana yang memuat biodata, foto, dan link sosial.
  2. Instruksi:
    1. Buat file index.html dengan struktur dasar HTML.
    2. Tambahkan judul, paragraf tentang diri sendiri, dan minimal 1 gambar.
    3. Gunakan CSS internal untuk memberikan warna latar, jenis font, dan margin.
    4. Kirimkan file .zip berisi index.html dan folder gambar.
  3. Rubrik Penilaian: Struktur HTML (30%), Styling & tampilan (30%), Konten & kelengkapan (20%), Keaktifan presentasi (20%).

LKPD English: Speaking Task "Daily Dialogue" (Kelas 7–8)

  1. Tujuan: Meningkatkan kelancaran dialog harian dan pengucapan.
  2. Instruksi:
    1. Pasangkan siswa, praktikkan dialog: greeting, asking about day, giving thanks.
    2. Rekam percakapan selama 1–2 menit menggunakan ponsel.
    3. Serahkan rekaman dan transkrip singkat (5–8 baris).
  3. Rubrik: Kelancaran (40%), Pronunciation (30%), Usage grammar (20%), Creativity (10%).

LKPD Math Olympiad: Problem Set (Kelas 8)

  1. Soal 1 (Combinatorics): Berapa banyak cara memilih 3 siswa dari 10 siswa? Jelaskan langkahnya.
  2. Soal 2 (Number Theory): Temukan semua bilangan 2-digit yang habis dibagi 7 dan 3.
  3. Soal 3 (Geometry): Dalam sebuah segitiga siku-siku dengan sisi 3 dan 4, berapa panjang sisi miring? Jelaskan dengan cara Pythagoras.
  4. Petunjuk Penyelesaian: Sertakan argumen singkat, diagram jika perlu, dan jawaban akhir.
  5. Rubrik: Ketepatan (50%), Keterbacaan & langkah (30%), Kreativitas pendekatan (20%).
